Telegram Kanban Bot — это бот для управления задачами в формате Kanban-доски прямо в Telegram.  
Он помогает командам создавать задачи, распределять исполнителей, отслеживать статусы и работать с проектом через удобные inline-кнопки.

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Status](https://img.shields.io/badge/status-in%20development-orange)

## Возможности

- создание команды;
- присоединение к команде по коду;
- создание задач через inline-кнопки;
- пошаговый ввод данных для задачи:
  - название;
  - описание;
  - исполнитель;
  - дедлайн;
  - приоритет;
- просмотр списка задач;
- изменение статуса задачи;
- работа с Kanban-доской;
- управление задачами без сложных команд;
- объектно-ориентированная структура проекта.
